# Buddy Budget

Persoonlijke budget-app in één bestand (`index.html`): inkomen, vaste kosten, maandbudgetten per categorie, uitgaven, analyse, vermogen en een meerjarenplan. Alles blijft in de browser (`localStorage`, optioneel versleuteld). Geen server, geen tracking, geen koersen ophalen.

- Openen: `index.html` in een browser, of hosten als statische pagina.
- Werkafspraken en de regel over persoonlijke data: `CLAUDE.md`.
- Audit en verbeteranalyse: `docs/audit-2026-09.md`.
